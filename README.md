# Pela Janela Games - PJG

Ambiente automatizado de producao e edicao de videos.

## Modos de producao

1. Narracao com roteiro.
2. Narracao sem roteiro.
3. Gameplay sem narracao.

## Estrutura

- core: motor de processamento.
- interface: interface grafica.
- config: configuracoes.
- scripts: scripts auxiliares e versoes anteriores.
- tests: testes automatizados.
- logs: registros de execucao.
- temp: arquivos temporarios.
- 01_gameplay_bruta: videos originais.
- 02_narracao_e_roteiro: narracoes e roteiros.
- 03_legendas_sync: legendas geradas.
- 04_cortes_prontos: videos finalizados.
- 05_assets: recursos visuais e sonoros.
